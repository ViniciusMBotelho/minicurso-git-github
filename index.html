Configuração: Sua Identidade no Git

COMANDOS NO REPOSITÓRIO
$ git config --local user.name "Seu Nome"
$ git config --local user.email "iniciais@aluno.ifnmg.edu.br"

Todo commit gravado no Git carrega o autor e o e-mail de quem fez a alteração.

ESCOPO DESTA PASTA
--local (Padrão do Lab)

Salva em .git/config. Garante que seu nome e e-mail fiquem vinculados apenas a este repositório sem alterar o restante da máquina.

--global (Sua Máquina)

Salva em ~/.gitconfig. Aplica para todos os repositórios do seu usuário no computador pessoal.

Em computadores compartilhados ou de laboratório, configure sempre com --local.

$ git config --list
core.repositoryformatversion=0 core.filemode=true core.bare=false remote.origin.url=https://github.com/... user.name=Seu Nome user.email=iniciais@aluno.ifnmg.edu.br
--local Repositório Atual
Gravado em .git/config. Tem a maior prioridade e sobrepõe os demais.
--global Usuário do Sistema
Gravado em ~/.gitconfig. Usado se não houver definição local.
--system Toda a Máquina
Gravado em /etc/gitconfig. Padrão para todos os usuários do SO.

Branches na Prática: Comandos Essenciais

01 · CRIAR

Criar Ramo

$ git branch minha-feature

Cria uma nova linha de desenvolvimento a partir do ponto atual sem sair de onde você está.

02 · ALTERNAR

Mudar de Ramo

$ git switch minha-feature

Muda para o ramo indicado. Também pode usar git checkout minha-feature.

03 · ATALHO

Criar & Entrar

$ git switch -c minha-feature

Cria o ramo e já muda para ele em um único comando (ou git checkout -b).

04 · LISTAR

Ver Ramos

$ git branch

Lista todos os ramos locais e destaca com * em qual você está agora.

Mão na Massa: Corrigindo o Bug

01

Proteger Segredos

$ echo ".env" >> .gitignore

Evite versionar logs, dependências e credenciais sensíveis.

02

Inspecionar Linhas

$ git diff

Revise as linhas alteradas antes de preparar qualquer arquivo.

03

Preparar Arquivos

$ git add nomearquivo

Mova as correções validadas para a área de staging.

04

Gravar Snapshot

$ git commit -m "fix: ..."

Escreva uma mensagem clara descrevendo o que foi resolvido.

Autenticação: Criando o Token & Push

NO GITHUB Gerar Token ↗
  • 1 Settings → Developer Settings → Personal access tokens → Tokens (classic)
  • 2 Clique em Generate new token (classic)
  • 3 Defina um nome no campo Note (ex: Minicurso Git)
  • 4 Marque o escopo: repo (Acesso total a repositórios)
  • 5 Copie o token gerado (ghp_...). Guarde bem!
⚠ O token não será exibido novamente após sair da página.
NO TERMINAL
$ git push -u origin main
Username: seu-usuario
Password: ghp_seutokenaqui...
Cole o token no campo de senha (os caracteres não aparecem ao colar)
